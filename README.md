# 컨퍼런스 Q&A

참가자가 QR로 접속해 질문을 등록하고, 진행자가 라운드마다 우수 질문 2개를 선정하는 웹앱.
정적 파일 + Supabase(무료)만으로 동작하며 도메인 구매가 필요 없습니다.

## 화면 구성

| 파일 | 대상 | 용도 |
|---|---|---|
| `index.html` | 참가자 (QR로 접속) | 질문 등록, 결과 확인 |
| `admin.html` | 진행자 | 라운드 시작/마감, 우수 질문 2개 선정, 질문 삭제 |
| `screen.html` | 빔프로젝터 | 실시간 질문 피드 + QR + 우수 질문 발표 |

라운드는 몇 번을 반복해도 **QR(주소)은 처음 것 하나를 계속 사용**합니다.
진행자가 "새 라운드 시작"을 누르면 모든 화면이 자동으로 전환됩니다.

## 1. 로컬에서 미리보기 (데모 모드)

`config.js`의 Supabase 값이 비어 있으면 데모 모드로 동작합니다.
데이터가 브라우저(localStorage)에만 저장되므로 혼자 시연할 때 사용하세요.

```bash
python3 -m http.server 5173
```

- 참가자: http://localhost:5173/
- 진행자: http://localhost:5173/admin.html (데모 모드는 암호 없이 입장)
- 스크린: http://localhost:5173/screen.html

## 2. Supabase 연결 (실제 운영)

1. https://supabase.com 가입 → **New project** 생성 (무료 플랜)
2. 대시보드 왼쪽 **SQL Editor** → `supabase.sql` 내용 전체를 붙여넣기
   - 실행 전에 파일 안의 관리자 암호 `workshop-2026`을 원하는 값으로 변경
   - **Run** 클릭
3. **Project Settings → API** 에서 두 값을 복사해 `config.js`에 입력
   - `Project URL` → `SUPABASE_URL`
   - `publishable` 키(sb_publishable_...) → `SUPABASE_ANON_KEY` (구버전 대시보드는 anon public / secret 키는 절대 넣지 말 것)

anon 키는 공개되어도 되는 키입니다(권한은 RLS와 함수의 암호 확인으로 제한됨).
관리자 작업은 전부 `supabase.sql`에서 정한 암호가 있어야 실행됩니다.

## 3. 배포 (무료)

**Netlify (가장 간단):** https://app.netlify.com/drop 에 이 폴더를 통째로 드래그&드롭.
나오는 `https://xxx.netlify.app` 주소가 참가자 접속 주소입니다.

**Vercel:** 폴더에서 `npx vercel` 실행 후 안내를 따르면 됩니다.

배포 후:
- 참가자 QR은 `https://배포주소/` 로 생성
- 진행자는 `https://배포주소/admin.html`
- 스크린은 `https://배포주소/screen.html` (전체화면 F11 권장)

`config.js`를 수정했다면 다시 드래그&드롭(재배포)해야 반영됩니다.

## 진행 흐름

1. 진행자: **새 라운드 시작** (제목 입력, 비우면 "라운드 N" 자동)
2. 참가자: QR 접속 → 질문 등록 (스크린에 실시간 표시)
3. 진행자: **질문 접수 마감** → 질문 목록에서 **⭐ 선정** 2개
4. 스크린/참가자 화면에 🏆 우수 질문 자동 발표
5. 다음 라운드: 다시 **새 라운드 시작** — QR은 그대로

## 참고

- 우수 질문은 라운드당 최대 2개까지만 선정됩니다 (초과 시 에러).
- 부적절한 질문은 진행자 페이지에서 삭제할 수 있습니다.
- 화면 갱신은 2~2.5초 간격 폴링이라 별도 설정 없이 실시간처럼 동작합니다.
- 지난 라운드의 선정 질문은 진행자 페이지 하단 "지난 선정 기록"과
  스크린 대기 화면에 표시됩니다.
